# Text Humanizer — AI-Style Checker & Rewriter

Check any text for AI-style patterns — highlighted sentence by sentence — then humanize it with a built-in rewriting engine and watch the score fall. **100% in your browser**: your text never leaves your device.

**▶ Live on Asif SaaS Studio:** open the tools catalogue and choose *Text Humanizer* (slug `text-humanizer`).

## What it does
1. **Intake** — paste text, or upload a document: **.docx, .pdf, .rtf, .html, .odt, .txt, .md** — each read by a real parser inside the page (legacy binary .doc is refused with Save-As guidance; scanned/subset-font PDFs get a clear "paste instead" message, never garbage).
2. **Check** — an AI-style score (0–100%) from five measured signals: stock machine phrases, sentence-rhythm uniformity, formal-word density, contraction absence, vocabulary diversity — with a full metrics table and colour highlighting (red / amber / green per sentence).
3. **Humanize** — phrase rules, plain-language word swaps, contraction restoration and sentence-rhythm repair; 4 tones × 3 strengths; deterministic output.
4. **Re-check & report** — the rewrite is scored again with the point reduction shown, and the full record downloads as **HTML, PDF, DOCX, DOC or JSON** (the PDF and DOCX are generated by writers built into the page).

## An honest note
The score is a **stylistic estimate**, not a GPTZero / Turnitin / Originality.ai / Copyleaks / Pangram score — those are proprietary server-side models, and no tool can honestly guarantee a pass on them. This app measures and removes the documented style patterns, and proves the change numerically. The full reasoning is in the test report and the documentation (Chapter 3).

## Use
Open `index.html` in any modern browser — or from this repo via any static host. No build step, no dependencies.

- Single file, **56.3 KB**, all CSS/JavaScript inline
- No localStorage, no service workers, no browser permissions, no parent-window access — safe in a sandboxed iframe
- Responsive layout in the Asif SaaS Studio emerald + lime branding

## Testing
16/16 engine checks; calibration: a machine-styled sample scores **62% → 28%** after humanizing, a hand-written sample scores **0%**. Intake parsers verified against real .docx/.odt/.rtf/.html/.pdf files; the exported DOCX opens in python-docx and the exported PDF reads back in poppler. Full report: `text-humanizer-test-report.md`.
